Xuất & Tải Dữ Liệu portals.json

Mọi chỉnh sửa trong trang quản trị này đều được tự động lưu tạm trong trình duyệt. Khi bạn sẵn sàng deploy chính thức lên GitHub & Cloudflare, hãy tải file portals.json này và ghi đè vào thư mục data/portals.json rồi push git!

Nhập Dữ Liệu Dự Phòng (Import)

Tải lên file JSON hoặc dán nội dung cấu hình để đồng bộ tức thì:

Hướng Dẫn Triển Khai GitHub & Cloudflare Pages

1 Lưu và tải file cấu hình portals.json mới nhất

Sau khi thêm hoặc chỉnh sửa các cổng dịch vụ, bấm nút "Tải File portals.json" ở trên và lưu đè vào thư mục dự án: data/portals.json.

2 Commit và Push mã nguồn lên GitHub

Chạy các lệnh terminal sau trong thư mục dự án:

git add . && git commit -m "Update postlain ecosystem portals" && git push origin main
3 Kết nối Cloudflare Pages với Repo GitHub
  • Truy cập Cloudflare Dashboard > Workers & Pages > Create application > Pages.
  • Chọn Connect to Git và chọn repository postlainmusic/postlain.
  • Framework preset: Chọn None (hoặc Direct HTML).
  • Build output directory: Để trống hoặc điền . (thư mục gốc).
  • Bấm Save and Deploy. Cloudflare sẽ tự động build và cấp domain miễn phí dạng postlain.pages.dev.
4 Gắn Tên Miền Tùy Chỉnh postlain.com

Trong trang quản lý Cloudflare Pages của bạn, chuyển sang tab Custom domains > Bấm Set up a custom domain > Nhập postlain.com và kích hoạt. Cloudflare sẽ tự động cấu hình DNS và cấp chứng chỉ SSL HTTPS miễn phí.
